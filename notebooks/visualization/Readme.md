# 🚦 Traffic Accident Analysis Dashboard (Power BI)

## 📌 Project Overview
This project focuses on building an interactive dashboard in Power BI to analyze traffic accident data and identify key factors affecting accident severity.

The dashboard enables users to explore accident patterns by location, time, weather conditions, and road features.

---

## 🛠 What Was Done in Power BI

### 1️⃣ Data Preparation
- Cleaned and transformed data using Power Query
- Handled missing values
- Standardized categorical fields (e.g., Day/Night)
- Created calculated columns
- Built data model and relationships

---

### 2️⃣ DAX Measures Created
- Total Accidents
- Average Severity
- % Accident in Rain
- % Accident at Night
- % Accident near Traffic Signal
- Average Visibility
- Average Severity (Measure)

---
